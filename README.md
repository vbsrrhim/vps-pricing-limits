## Кому хватит 1 vCPU, а кому нужен 4 vCPU

Для личного VPN на 10–30 пользователей обычно хватает 1 vCPU, 1–2 ГБ RAM и 10–20 ГБ NVMe. Для 100+ пользователей стоит смотреть на 2–4 vCPU, 4–8 ГБ RAM и канал от 200–500 Мбит/с. Это ориентиры по нагрузке, а не гарантия для любого софта.

Под эти ориентиры хорошо попадают VPS One для небольшого VPN и Basic или Lucky для VPN на 100+ человек. У Basic и Lucky порт 1 Гбит/с. Наличие AES-NI в карточках AVA Hosting не указано. Для WireGuard и OpenVPN это стоит уточнить у поддержки до оплаты, потому что без аппаратного ускорения шифрования нагрузка на CPU будет выше.

Для сайта с панелью и базой данных я бы начинал с Basic за 10 €/мес. 2 vCPU и 4 ГБ RAM дают запас, которого не будет у VPS One с 2 ГБ. Lucky за 15 €/мес имеет смысл, если сайтов несколько или база уже заметно нагружает сервер.

Если вы собираете персональные данные россиян, зарубежный VPS сам по себе не решает требования 152-ФЗ. База с персональными данными граждан России должна находиться в России.
